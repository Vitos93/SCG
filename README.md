# Академия SCG

Мобильное приложение с курсами и книгами для руководителей отделов продаж (РОП) и менеджеров по продажам (МОП).

**Sales Consulting Group**

## Открыть приложение

Веб-версия (открывается в браузере на любом устройстве):
https://vitos93.github.io/SCG/

## Скачать Android-приложение (APK)

https://github.com/Vitos93/SCG/releases/download/v1.0/SCG.apk

При установке Android может показать предупреждение о неизвестном источнике — это нормально для приложений не из Google Play. Нажмите «Подробнее» → «Всё равно установить».
